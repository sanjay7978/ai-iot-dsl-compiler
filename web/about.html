AboutCompiler Design project

An AI-assisted DSL compiler
for IoT automation.

Smart homes are programmed by people who are not programmers. Kelvin lets them describe what they want in English, and then treats that description the way a compiler treats source code: exactly, phase by phase, with clear errors.

An AI model turns a sentence like “if the temperature is above 30 and the door is open, turn on the fan” into a small rule language. From there, a compiler written by hand in C++ does the real work: scanning, LL(1) parsing, building the syntax tree, type checking and rule analysis, three-address code, CFG-based optimization and code generation for four targets.

The AI never has the last word. Every answer it gives is compiled and checked, and the website shows each phase of that work, so you can see how the compiler reached its result.

Hand-written, not generated

No Lex, Yacc or parser generators. The scanner is a coded DFA and the parser is recursive descent, so every decision in the compiler can be read and explained.

No dependencies

The compiler is plain C++17. The server uses only the Python standard library. The website is vanilla HTML, CSS and JavaScript with self-hosted fonts, and it works offline.

Tested across targets

The test suite checks every phase, and it runs the C, Python and JavaScript output of each example with several inputs to confirm they all behave the same way.
